## miu edition v1.4.0

- Windows graphical Hermes full-backup restoration workflow.
- Privacy-neutral backup picker and runtime installation discovery.
- Embedded kitten illustration, blue/pink theme and readable logs.
- CRC/path validation, official importer, configuration checks and temporary-file cleanup.
- Fixed custom button background artifacts in real Windows rendering.

Download the ZIP, extract it and run HermesRestore.exe. No Python/Node installation is required for this tool. A current Hermes installation is required. The EXE is unsigned; checksums are provided.

This initial public release is an independent community tool. Actual restoration on a fresh installation needs further end-to-end testing. No user backups or credentials are included.
