# 恢复说明

选择正确全量备份和全新安装位置，先检查、后恢复。安装目录下方显示真正的数据恢复目录；设置 `HERMES_HOME` 后，两者可能不同。

恢复关闭可识别的 Hermes 进程，创建临时用户数据副本，保留本机程序/运行状态文件，通过官方 importer 恢复，再核对文件存在性和关键内容哈希。数据库由官方 SQLite 恢复逻辑处理，体检另做 quick_check。

不创建保护备份，不提供回退。如果发生部分导入或超时，请保存脱敏日志供排查，必要时重新完成干净安装，再用原始备份恢复。卸载不一定删除用户资料，需核对安装方式。

本地体检与账户接口检查不能代替实际对话、消息收发、授权、记忆检索和定时任务检查。备份外的文件和依赖不会自动补齐。没有自动执行本地补丁或安装第三方包。
