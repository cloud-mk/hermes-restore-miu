# 隐私说明

公开源码没有绑定某个用户的备份文件夹、用户名或备份文件。选择备份从系统“文档”目录开始；备份选择初始为空。

安装位置通过当前用户的 `HERMES_HOME`、系统 LocalApplicationData 与 PATH 动态定位。运行时显示本机实际路径是为了确认恢复目标，仓库截图使用虚构示例。

恢复在本机执行，工具不上传 ZIP 或用户数据。临时 ZIP 可能含凭据，结束后尝试删除；失败会显示日志。异常退出遗留文件在下次启动清理，需满足该工具的文件名规则并超过 24 小时。

点击账户接口联网检查会调用 Hermes 官方 `usage` 命令；点击网关启动可能连接配置的消息服务。恢复中的官方 import 也可能短暂启动网关。这些行为使用 Hermes 自身配置。

日志会隐藏已读到的常见环境变量值、auth 凭据、Bearer、常见密钥格式和 URL 查询参数，但无法保证识别任意日志中的个人信息。分享日志前请检查；不要提交完整备份、`.env`、auth 文件、数据库或未脱敏日志。
