# 验证说明

核心测试使用临时合成 ZIP，不使用个人备份。覆盖 CRC、危险路径拒绝、程序文件保留、关键配置差异检测与时间格式。

开发过程另在隔离目录验证了模拟 CLI 的恢复流程、失败/超时、临时副本清理、安装检测与进程识别。未对真实用户资料执行覆盖恢复。

自绘按钮必须检查实际桌面合成窗口，而非仅依赖 DrawToBitmap。当前版本已检查两种窗口尺寸下正常、悬停、按下、禁用状态及 320 个可见按钮边角，修复了原生透明背景导致的黑色/蓝色色块。未来 UI 改动需重新做真实窗口检查。

仓库截图使用虚构的路径与日志，不能作为真实用户数据恢复成功的证明。GitHub Actions 运行核心测试；不同安装方式与实际重装流程仍需进一步验证。

## v1.5.0

在当前 Windows 200% 缩放下检查真实合成窗口，窗口为 1920×1320 和 1520×1120 物理像素（约 960×660、760×560 逻辑像素）。检查正常、悬停、按下、禁用状态和 288 个按钮边角。截图仅作为视觉检查；核心测试继续使用合成 ZIP。不同物理显示器之间的 DPI 切换尚未实测。

启用 .NET Framework 4.8 TargetFramework、Windows 10 兼容清单以及 PerMonitorV2 配置；窗口初始化期间暂停布局，避免字体 DPI 更新早于子控件构建而导致尺寸不同步。
